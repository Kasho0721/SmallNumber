# 小企有数：小微商户财税体检助手

面向没有专职会计的个体户和小微商户：引导填写经营数据 → 计算财税指标 → 匹配优惠政策并给出原文出处。
**只做信息整理和政策指引，不提供税务或财务建议。**

## 快速开始

```bash
# 后端（Python 3.10+）
cd backend
pip install -r requirements.txt
cp .env.example .env          # 填 LLM_API_KEY；不填也能跑（演示模式）
uvicorn app.main:app --reload --port 8000

# 前端（Node 18+），另开一个终端
cd frontend
npm install
npm run dev                   # 手机和电脑连同一个 Wi-Fi，用终端里的 Network 地址打开
```

打开后点“没有照片？先看示例”→“开始体检”，就能看到完整报告。接口文档：http://localhost:8000/docs

## 目录

```
backend/app/
  schemas.py          全组共用的数据格式（唯一来源，改之前先说）
  llm.py              统一的模型调用，任何 OpenAI 兼容接口，换模型只改 .env
  main.py             所有 API 路由
  modules/intake.py     A：拍照识别 + 对话追问
  modules/diagnosis.py  B：指标计算 + LLM 解读
  modules/policy.py     C：政策库、匹配、问答（RAG）
  modules/guide.py      政策引导填写：办理步骤 + 申报表各栏参考金额 + 上海税务局文件链接
  data/policies.json    C：政策库（6 条，已按 2026 年增值税法更新，含上海城建税）
  data/sources/         政策原文摘录（上海市税务局等官网，注明出处）
frontend/src/
  types.ts            与 schemas.py 对应的前端类型
  App.tsx             录入 / 体检报告 / 问政策 三个页面
samples/              真实或示例账单数据（JSON）
```

## 数据流

```
拍照/对话（A） ──► BusinessData ──► 指标计算（B）──┐
                        │                          ├─► Diagnosis ──► 体检报告页
                        └──► 政策匹配（C）─────────┘
用户自由提问 ──► 政策问答（C，RAG + 出处）
```
